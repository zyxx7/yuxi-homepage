PROJECT 01 / 2023.12—2024.05 · 项目主要成员

慧眸矫姿坐姿监测系统

把摄像头画面，转成姿态线索。

项目内容

基于 MoveNet 构建摄像头实时坐姿识别流程，围绕图像采集、姿态识别和训练进行实践。

我的工作

负责姿态识别算法实现与图像数据采集，参与模型训练，配合改进坐姿识别效果。

实践体会

这项实践让我接触到从摄像头图像到人体姿态表示的处理过程，也成为继续学习计算机视觉的起点。

PROJECT 02 / 2023.11—2024.11 · 后端开发

校易班综测平台二次开发

让综合测评的数据更好管理。

项目内容

为校易班综测平台进行二次开发，使用 Spring Boot 编写学生信息与综合测评数据管理模块。

我的工作

实践体会

这次主要做后端，除了实现功能，也需要考虑已有数据结构与实际使用中的查询需求。

PROJECT 03 / 2024.05—2024.07 · 独立开发

微博舆情分析系统独立开发

从一条评论，看到讨论的倾向。

项目内容

使用 Python 和 Flask 搭建后端，采集并清洗微博评论，结合自然语言处理方法分析评论情感。
